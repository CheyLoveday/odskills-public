# Replace regularity with structural complexity

State exactly which assertion the downstream result uses. Possible
substitutes for an invertible graph include a bounded sheet count for a
projection, a bounded-rank module of functions, or finitely many strata with
uniform estimates. Prove the relevant bound on the declared domain, with
multiplicities if the consumer counts them.

A finite analytic cover can ramify or have monodromy. Prove separate
single-valued analytic branches only if the consumer needs them, on domains
where they exist. A fibre cardinality estimate does not supply derivative
bounds, holomorphic extensions or uniform analytic norms. Track branching
and omitted points separately. If a determinant argument consumes the cover,
use the [determinant budget](../runbooks/finite-cover-determinant-budget.md).
