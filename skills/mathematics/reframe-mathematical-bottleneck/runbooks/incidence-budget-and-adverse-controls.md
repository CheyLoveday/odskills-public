# Incidence budgets and adverse controls

Use when a catalogue or a residual arithmetic configuration controls the
remaining bound.

1. Define the source count, including weights, equality of objects and any
   height cutoff. Write the map or incidence relation from source objects
   to generators. State whether each source object has a manifestation
   and what would justify counting it only once.
2. Bound the generator catalogue and its fibres separately. Transfer
   through the correct incidence inequality. For an upper bound on original
   points via total incidences, ensure each original point appears and each
   counted incidence contributes to the bound used. Include uncovered
   points and preserve weighting conventions.
3. Make a margin table with regimes, local estimates, analytic and
   arithmetic costs, multiplicity factors, exceptional terms and signed
   slack. Verify the regimes exhaust the declared source and sum the
   inequalities with uniform constants. State a precise missing estimate
   for each surviving branch.
4. If an intermediate implication may be too strong, freeze the retained
   assumptions and independently verify an adverse model. Record exact
   arithmetic and coverage for finite checks. Say which original source
   constraint is absent when the model has no proved lift.

Return the exact net inequality or a scoped open budget. The generator
count is evidence about the original target only through the proved transfer.
An adverse model can show which additional condition needs to exclude a
surviving configuration. Preserve its status as a model of the stated
relaxation unless a source witness is supplied.
