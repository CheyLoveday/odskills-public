# Review {brief or receipt}: {change and snapshot}

Template owned by [plan-development-work](../SKILL.md). A brief requests checks;
a receipt records checks actually performed. Select
[review-code-change](https://github.com/CheyLoveday/odskills-public/blob/main/plugins/odskills/skills/review-code-change/SKILL.md)
for the review procedure when available. Neither this form nor an author's PASS
is reviewer approval. Keep only questions relevant to the contract.

## Inputs and scope

- Mode: requested review (NOT_RUN) / completed review:
- Intended behaviour, requirements, non-goals and project review policy:
- Exact reviewed source/diff/base; dirty paths/content identity if relevant:
- Primary code, callers, tests and receipts; author's claims versus primary evidence:
- Allowed effects and reviewer independence/context:

## Checks to select or report

- [ ] Trace the changed behaviour through the actual public consumer.
- [ ] Challenge the important failure route with a valid positive and adverse case.
- [ ] Check compatibility, partial writes, overwrite/error/resource behaviour where relevant.
- [ ] Confirm test selection, result counts/skips and source/environment binding.
- [ ] Preserve original evidence; do not repair or mutate the reviewed source unless requested.

These are review prompts, not completed checks. For each selected check record
planned or actual actions and limitations; no hypothetical defect is required.
