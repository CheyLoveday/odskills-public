# Support

Use [GitHub issues](https://github.com/CheyLoveday/odskills-public/issues) for
skill or tooling problems and [pull requests](https://github.com/CheyLoveday/odskills-public/pulls)
for contributions. Include the skill ID, source pin, host and a small
shareable example. Use the [contributor guide](CONTRIBUTING.md) for local checks.
Keep credentials and private project material out of reports.
