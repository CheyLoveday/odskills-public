# Support

Maintainer: Chey Loveday.

Use [odskills-public issues](https://github.com/CheyLoveday/odskills-public/issues)
for installation problems, reproducible bugs, privacy questions and feature
requests. Include the release version, host/version, selected skill, expected
behavior and a minimal synthetic reproduction. Remove credentials, local user
paths, proprietary source and sensitive data before submitting. Do not upload
raw session logs without reviewing them. This is best-effort community support;
no response-time guarantee is offered. Confidential incident reporting is not
yet provided through this route; do not post sensitive details publicly.
