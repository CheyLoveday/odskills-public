# Worked example of a bound across two projects

A lattice enumeration project counts original records in its active
population and has an open issue for a uniform exponent below
`1/2`. Its source map sends each active record to an actual grid tile.
A geometry project bounds the number of those tiles by `N^(1/5)` and
an independently maintained proof bounds the full fibre of each such
tile by `N^(1/4)`. The two statements use the same tiles, original
records, revision and positive scale `N`.

The original count is the sum over these fibres. Its exponent is
`1/5 + 1/4 = 9/20`, with strict slack `1/20`. Return this bounded
application to the existing receiving issue. If the theorem also counts
records outside the active population, carry those separately.

A different map retains only sampled representatives in equally named
tiles. Its smaller sample count yields no bound on the original fibres.
The needed bridge would bound or cover every original record missed by
that sample. Two valid witnesses may establish two independent sample
existences, where that is the task's actual quantifier structure.
