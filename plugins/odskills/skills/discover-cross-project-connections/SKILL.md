# Discover cross-project connections

## When to use

Select this experimental skill explicitly for a bounded mathematical portfolio.
If the receiving theorem and bridge are already known, go directly to the
relevant proof or audit.

## Inputs

Take the independent projects, new findings, old blocked obligations and
the sources the user allows you to inspect.

## Procedure

1. **Reconcile the evidence.** Identify actual working revisions, canonical
   owners, open questions and earlier attempts. Distinguish unavailable
   sources from sources searched without a match. Read the owner evidence
   for any decisive status and keep local proof, independent review and
   formal replay separate.
2. **Compare interfaces.** For each promising supplier or need, state the
   original objects, quantified inputs and outputs, map direction,
   assumptions, known evidence and relevant units or costs. Abstract the
   mathematical mechanism when it helps locate a plausible consumer.
3. **Look forward, backward and across.** Ask which receiving problems a
   result could advance, including previously blocked ones. Ask what could
   satisfy an open guard. Compare mechanisms across different carriers.
   Check existing owner work before claiming a new connection.
4. **Check the receiving consequence.** Name an exact receiver for each
   strong lead. Prove an applicable substitution or isolate the first
   unproved premise. Check simultaneous source, revision and guard
   compatibility where required. Preserve valid independent witnesses
   where the receiver needs only separate existences. For a quantitative
   claim, account for fibre costs, strict net margin and coverage. Try one
   tempting wrong match such as a stale projection or a reversed implication.
5. **Return a bounded handoff.** Rank the supported connections by what
   they change for the receiver and how checkable the next obligation is.
   Distinguish a proved application, conditional bridge, method transfer,
   generalization, countercontrol and already-owned result. Reuse the
   canonical receiving issue where one exists. Draft any proposed referral
   unless the user has authorized a write.

## Outputs

Use the [handoff and comparison guide](references/handoff-and-comparison.md)
when recording referrals or running a paired comparison. The
[worked example](examples/partition-and-fibres.md) shows a proved local
transfer and an incompatible match. Optional mathematical specialists
can check a selected proof obligation when available.

Return the source and receiver revisions, actual consequence or first open
premise, adverse control, remaining scope, and the owner route for the
strongest connections.

## Verification

Recompute load-bearing inequalities or substitutions and check the adverse
control on its actual source. Recheck affected edges after a source revision.

## Stop

Keep parked leads and their re-entry conditions brief. A missing premise
prevents the dependent application. End at the selected portfolio boundary
or report why the supplied evidence supports no referral.
