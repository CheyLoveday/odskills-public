## Compare two fresh runs

1. Save one portfolio snapshot, the same prompt and allowed source scope.
   Set comparable tool access, time and effort for both runs. Keep the
   exact expected edges and adverse cases on the evaluator side when a
   controlled test is possible.
2. Select this skill explicitly in one fresh session. Use the same
   prompt in another fresh session with the selector omitted. Keep other
   guidance and settings matched. Verify actual reads where the host
   exposes them.
3. Compare the qualified receiving consequences, missed valid connections,
   false joins, residuals, owner routing, and the check needed to reuse the
   output. Record the two artifacts and what differs. Treat ties or a
   single-case improvement as scoped evidence.
