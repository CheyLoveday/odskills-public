# Reverse-engineer theorem budgets

Write the global bound with all multipliers, regime sums and exceptional
contributions. Solve backward for a sufficient local inequality and show
substitution closes the original target. For a power product, add the scale
exponents with their signs and subtract that total from the target exponent.
For a finite sum with uniform constants, use the largest exponent. If the
number of terms grows with the parameter, include its cost. Account separately
for any needed rate margin, coefficient budget or endpoint estimate.

List the old and proposed local terms, transport costs and signed slack under
the same hypotheses. State whether the local threshold is merely sufficient.
Use exact rational arithmetic for rational exponents. Identify which new
estimate is genuinely needed and which route already falls within the budget.
