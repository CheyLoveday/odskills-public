# Representation bottleneck triage

Use when a stated proof first stalls at a coordinate, inverse, or regularity
condition. Fix the source claim and the estimate that consumes the chart.
If the failure is an independent arithmetic estimate, keep the chart and
identify that estimate instead.

1. Record the current source map, projected variables, admissible domain,
   exceptions, fibre complexity, scales and the first estimate that fails.
2. Give a serious alternative and the map on the same source objects.
   Check separately what is covered, how many times it can be counted, and
   whether the reverse direction is needed. Any excluded locus needs its
   own term or a proof that it is outside the source.
3. Substitute each mode into the same consumer. Keep every multiplier,
   domain change, norm, denominator and counting term visible. State the
   minimum sufficient improvement and compare signed margins after losses.
4. Return the selected route or keep the current one. Name the first
   unproved statement on which any recommendation depends.

For example, suppose a bound is linear in a chart width. The old width
is at most $X^{-1/3}$. An alternative supplies $X^{-1/2}$ under the same
coverage, but transfers the bound at a cost $X^{1/4}$. For $X\ge1$, the new
effective width is at most $X^{-1/4}$. That estimate gives a weaker
guarantee than the old one. The smaller raw coordinate does not justify a
change on this evidence.

Use the [finite-cover determinant budget](finite-cover-determinant-budget.md)
if a bounded-sheet alternative feeds a determinant. Use the
[incidence budget](incidence-budget-and-adverse-controls.md) if the counted
object or the remaining arithmetic regimes change.
