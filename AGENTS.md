# Agent instructions for odskills

Use the [catalogue](catalogue/skills.md) to find the skill that fits the task.
Read its `SKILL.md` and the referenced resources it calls for. Record the
source pin when using a package in another project. Follow that project's
instructions and the user's authority for commands, installations and effects.

The authoritative packages live under `skills/<domain>/<id>/`. Preserve each
skill's ID and scope. Edit it there and regenerate the catalogue and plugin
projection using the [local checks](CONTRIBUTING.md#local-checks). Keep source,
package verification, native discovery and actual application distinct in
test reports. Use shareable fixtures in this public repository.
